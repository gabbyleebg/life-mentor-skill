# Life Mentor · Five-Part Review Skill

一套适用于个人日常反思与长期成长的中文 AI Skill。将自然口述、语音转写或零散笔记整理为**保留原话风格的五部分复盘**，并在使用者明确要求时提供行动规划与成长追踪。

## 它能做什么？

- **忠实整理**：保留第一人称、表达习惯和真实意思；不把口述改成励志文章。
- **五部分复盘**：①坦诚错误或不足 ②感恩 ③他人的需求 ④自己的需求 ⑤未来的展望。
- **谨慎分析**：区分事实、猜测、愿望和决定，不替使用者推断他人动机。
- **按需行动**：仅在请求时给出优先任务、时间安排或复盘对比。
- **长期追踪**：根据实际提供的历史记录，检查行动与结果，而不是凭印象判断进步。

## 适合谁？

希望用口述、日记或 AI 对话来改善自我觉察、时间管理、关系沟通、职业发展与生活规划的人。

## 快速使用

1. 打开 [`SKILL.md`](./SKILL.md)，复制其中的说明到支持自定义指令或 Skills 的 AI 工具中；不同平台的安装方式可能不同。
2. 输入一段当天的语音转写或文字复盘。
3. 发送：**“请按五个板块整理，保留我的语言习惯，不要添加你的理解。”**
4. 如需进一步分析，再单独提出：“请分析这周反复出现的一个问题，并给出三项可执行行动。”

## 示例输入

> 昨天我做事情没有排好优先级，先处理了临时消息，最重要的材料反而没做完。不过我很感谢同事愿意配合。我觉得他们需要更清楚的说明，我自己需要学会提前安排。以后希望工作更有条理。

## 示例输出（节选）

### 一、坦诚错误或不足
昨天我没有排好事情的优先级，先处理临时消息，最重要的材料反而没有完成。

### 二、感恩
我很感谢同事愿意配合。

### 三、他人的需求
我觉得同事需要更清楚的说明。这是我的判断，还需要进一步沟通。

### 四、自己的需求
我需要学会提前安排，不要总被临时事情带走。

### 五、未来的展望
我希望以后工作更有条理。

## 隐私与边界

- 本项目不包含创作者或使用者的私人复盘、家庭经历、身份信息或真实聊天记录。
- **不要把个人日记或包含他人隐私的内容上传到公开 GitHub 仓库。**
- AI 可能误解语音转写；涉及不清楚的人名、日期和意思，应先确认。
- 这是一种反思与整理工具，不替代心理咨询、医疗、法律或财务专业服务。
